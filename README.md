# Student Grade Tracker GUI

A simple Java Swing application to manage student grades.

## Features
- Add, update, and remove students
- Calculate average, highest, and lowest grades
- Display letter grades (A–F)
- Generate summary reports

## Technologies
- Java
- Java Swing

## How to Run
```bash
javac StudentGradeTrackerGUI.java
java StudentGradeTrackerGUI
```
